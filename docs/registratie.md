# Registratie – US 1.1

`snippets/registratie.php` is een conceptimplementatie op basis van de beschreven registratie. De oorspronkelijke actieve snippet is niet integraal teruggevonden. Vergelijk deze code met Code Snippets voordat je hem activeert.

Shortcode: `[custom_register]`. Verwerking via WordPress-gebruikersaccounts, formuliercontrole en klantrol.

## Testen
- Geldige registratie en unieke gebruikersnaam/e-mail.
- Ongeldige nonce, korte wachtwoorden en dubbele accounts.
- Klantrol zonder beheerrechten.
- Controleer de pagina-slug voor inloggen.
