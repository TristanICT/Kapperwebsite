# B1-K1-W3 – Realiseert (onderdelen van) software

Gebaseerd op het werkblad B1-K1-W3 van het aangeleverde beoordelingsformulier. Elk criterium heeft maximaal drie punten. Gerealiseerde functionaliteit, kwaliteit code en versiebeheer zijn cruciaal.

| Criterium | Bewijs en vervolg |
|---|---|
| Gerealiseerde functionaliteit | Aangeleverde reserveringscode; voeg bewijs van werking en planning toe. |
| Kwaliteit opgeleverde functionaliteiten | Vergelijk met de eisen en wensen uit K1-W1; leg werkelijke testresultaten vast. |
| Kwaliteit code | Functies, invoercontrole, WordPress-databasefuncties, unieke datum/tijd-combinatie; controleer de code en voer tests uit. |
| Versiebeheer | Branches, commits en pull requests met echte wijzigingen; volg ook toekomstige wijzigingen van de actieve snippets. |

De GitHub-import en documentatie zijn met hulp van ChatGPT gemaakt op 24 november 2026. Dit is geen historisch bewijs van versiebeheer tijdens eerdere ontwikkelweken. De actieve WordPress-installatie en testresultaten zijn nog niet geverifieerd. De kandidaat controleert de broncode en licht het eigen werk zelf toe.
